# User Stories

## User Story 1
**As a** dealer,  
**I want to** view the available products,  
**so that** I can evaluate and select products easily.

## User Story 2
**As a** dealer,  
**I want to** view product details,  
**so that** I can make an informed evaluation.

## User Story 3
**As a** dealer,  
**I want to** submit my evaluation,  
**so that** the product evaluation can be recorded.

## User Story Template

**As a** [user/role]  
**I want to** [action or feature]  
**So that** [benefit or reason]
